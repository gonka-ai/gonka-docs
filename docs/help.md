# Get Support on Discord

Join the Gonka community on [Discord](https://discord.gg/REcpeYc7P7) if you need assistance.

To contribute code or propose ideas, see the [Bounty program](bounty-program.md). Submit every security vulnerability on [HackerOne](report-vulnerability.md) first. That submission is the one that can be paid. Do not open a public GitHub issue or pull request, and do not post the issue in Discord or other public channels. A fix is optional, and it comes second: after the HackerOne report exists, open **Security and quality → Report vulnerability** on [`gonka-ai/gonka`](https://github.com/gonka-ai/gonka/), put the HackerOne report number in the title, then create a private fork from that report and open the fix there.
