# Get Support on Discord

Join the Gonka community on [Discord](https://discord.gg/REcpeYc7P7) if you need assistance.

To contribute code or propose ideas, see the [Bounty program](bounty-program.md). Report every security vulnerability privately. Do not open a public GitHub issue or pull request, and do not post the issue in Discord or other public channels. To be eligible for a bounty, submit it on [HackerOne](report-vulnerability.md). That submission is the one that can be paid. If you can't or prefer not to join the bounty program, report privately [on GitHub instead](https://github.com/gonka-ai/gonka/security/advisories/new). Reports submitted this way are not eligible for a bounty. For HackerOne reports, a fix is optional, and it comes second: after the HackerOne report exists, open **Security and quality → Report vulnerability** on [`gonka-ai/gonka`](https://github.com/gonka-ai/gonka/), put the HackerOne report number in the title, then create a private fork from that report and open the fix there.
