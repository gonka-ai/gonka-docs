# Ethereum 桥概述

!!! warning 
    始终先进行小额测试交易。桥接转账是不可逆的，因此在转移大额资金前，请先发送一小笔金额并确认其已按预期到达。

    由 Gonka 共识控制的专用桥智能合约已部署在以太坊的地址为：

```text
0x972a7a92d92796a98801a8818bcf91f1648f2f68
```

[在 Etherscan 上查看桥合约](https://etherscan.io/address/0x972a7a92d92796a98801a8818bcf91f1648f2f68){target=_blank}

!!! important "此地址也是 WGNK 代币"
    桥合约**就是** **WGNK** ERC-20 代币——它们是同一合约，位于此地址，而非两个独立合约。因此，上述 Etherscan 页面同时是桥和 WGNK 代币。通过桥接*进入* Gonka 的封装 ERC-20 代币在 Gonka 一侧以 CW-20 代币形式存在；只有 **WGNK** 存在于以太坊上，且就是此合约。

!!! tip "将 WGNK 添加到您的以太坊钱包"
    WGNK 是标准 ERC-20 代币，因此您可以在任何支持 ERC-20 的钱包中将其作为**自定义代币**添加——例如 MetaMask、Trust Wallet、Ledger 浏览器扩展等。使用上述桥合约地址（`0x972a7a92d92796a98801a8818bcf91f1648f2f68`）作为代币合约地址——它既是桥，也是 WGNK 代币。

!!! note "安全审计"
    该桥已由 [CertiK](https://skynet.certik.com/projects/gonka){target=_blank} 审计。完整报告可在 CertiK Skynet 页面上获取（Gonka–Ethereum 桥审计与共识和推理审计并列），以及本地副本：[CertiK Gonka–Ethereum 桥审计（PDF）](../../assets/audits/CertiK-Gonka-Ethereum-Bridge-Audit.pdf){target=_blank}。

    该桥允许您转移：

* **任何 ERC-20 代币**（例如 [USDT](https://etherscan.io/token/0xdAC17F958D2ee523a2206206994597C13D831ec7){target=_blank}、[USDC](https://etherscan.io/token/0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48){target=_blank}、[WETH](https://etherscan.io/token/0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2){target=_blank}）在以太坊和 Gonka 之间来回转移。
* **原生 Gonka 代币（GNK）** 与以太坊之间（作为封装的 GNK）来回转移。

!!! note "ETH 以 WETH 形式桥接"
    桥会追踪**ERC-20 代币转账**到桥合约。原生 ETH 不是 ERC-20，因此要桥接以太币，您必须先在以太坊上将其封装为 **WETH**（标准封装以太币 ERC-20 代币），然后像其他 ERC-20 代币一样桥接 WETH。

!!! important "任何 ERC-20 代币均可使用——无需注册"
    您可以桥接**任何** ERC-20 代币，即使该代币从未在 Gonka 上注册过。当存款被识别时，桥会自动创建封装的 CW-20 合约并铸造您的余额。通过治理注册是**可选的**，仅添加显示元数据（名称、符号、小数位）和交易资格——**无需**注册即可转移代币。请注意，未注册时，小数位可能与原代币不匹配，这是正常现象。在代币注册前，其封装版本可能无法反映原代币的小数位。这是正常现象，不影响您的余额。详情请参见 [注册桥接代币](register-token.md)。

!!! important "两个地址来自同一密钥"
    Gonka 将封装代币发送到**由与签署以太坊存款相同的公钥派生**的 Gonka 地址。如果您以助记词派生以太坊和 Gonka 密钥，它们通常是**不同**的密钥，这将无法工作。不要使用助记词派生 Gonka 地址并假设它与您的以太坊地址一致，两者的派生方式不同。在首次转账前，请阅读 [地址与密钥](addresses-and-keys.md)。

## 概述

### 将 ERC-20 代币（例如 USDT）从以太坊封装到 Gonka
1. **存款**：ERC-20 代币的所有者将代币发送到以太坊上的桥智能合约地址。
2. **锁定与铸造**：代币被锁定在合约中。每个 Gonka 主机运行一个小的桥接容器，监控桥地址。一旦存款在以太坊上**确认**，且**超过 50% 的主机（按投票权）** 独立确认后，桥将在 Gonka 链上铸造该 ERC-20 的封装版本作为 CW-20 代币。
3. **每个代币一个封装合约**：每个以太坊代币映射到 Gonka 上**唯一一个**封装的 CW-20 合约（由链 ID + 以太坊合约地址标识）。首次存款会实例化该合约；后续对**相同**代币的存款将复用**同一**封装合约。只有桥可以实例化这些合约或铸造其代币。
4. **所有权**：铸造后，封装代币的所有权分配给与以太坊上使用的私钥/公钥对相同的 Gonka 地址。此后，所有者可自由将封装代币转移到任何其他 Gonka 账户。请参见 [存款 USDT（以太坊 → Gonka）](deposit-usdt.md) 了解详细流程。

!!! note 
    注册代币（参见 [注册桥接代币](register-token.md)）是可选的。它不影响代币能否被桥接——仅附加元数据，以便封装代币在钱包和仪表板中显示正确的名称/符号/小数位，并使其有资格进入链上流动性池。USDT 和 USDC 已预先注册。您可以在不注册的情况下桥接和测试任何其他 ERC-20 代币。

### 解封装 / 提回以太坊
1. **请求**：所有者在 Gonka 链上提交特殊的提款交易。这会锁定/销毁封装代币并触发 BLS 签名生成。
2. **签名检索**：使用提供的 API 端点检查签名生成状态。
3. **执行**：一旦生成 BLS 签名，即可用于向以太坊上的桥合约发送提款命令。合约验证签名后，将原始代币释放到目标以太坊地址。请参见 [提款 USDT（Gonka → 以太坊）](withdraw-usdt.md) 了解详细流程。

### 将原生 GNK 封装为以太坊（WGNK）
1. **托管**：特殊交易将 GNK 锁定在托管账户中，并触发 BLS 签名生成。
2. **执行**：生成的 BLS 签名提交到以太坊上的桥合约，以向目标以太坊地址铸造 WGNK。请参见 [存款 GNK（Gonka → 以太坊）](deposit-gnk.md) 了解详细流程。

!!! note 
    GNK 在以太坊上**从未**以原生形式存在。在以太坊一侧，它始终是封装的 **WGNK** ERC-20 代币——且该代币**就是桥合约本身**（同一地址；桥合约也是 WGNK ERC-20）。“将 GNK 桥接到以太坊”意味着在 Gonka 上锁定原生 GNK，并在以太坊上铸造等量的 WGNK。

### 将 WGNK 从以太坊返还为 GNK
1. **燃烧**：WGNK 被发送到以太坊上的桥接合约，随后被燃烧。
2. **释放**：一旦 Gonka 共识确认了燃烧操作，等量的原生 GNK 将从托管中释放到由与燃烧 WGNK 相同密钥派生的 Gonka 地址。参见 [提取 GNK（以太坊 → Gonka）](withdraw-gnk.md)。

### 桥接 ETH（作为 WETH）
桥接合约检测 ERC-20 转账，而非原生 ETH 转账。要将以太坊转入 Gonka：

1. **封装**：在以太坊上将你的 ETH 封装为 **WETH**（标准的封装以太坊 ERC-20）。
2. **桥接**：将 WETH 发送到桥接合约——其行为类似于 [任何其他 ERC-20 存入](deposit-usdt.md)。Gonka 将封装的 WETH 作为 CW-20 代币铸造到由相同密钥派生的 Gonka 地址，你可以通过相同方式将其提取回以太坊。

## Gonka → 以太坊的授权方式（每日群组密钥）

所有从 Gonka **发出** 的转账（提取封装的 ERC-20/ETH 或铸造 WGNK）均通过 Gonka 验证者集的 BLS 签名在以太坊上释放。为使以太坊桥接合约信任该签名，它必须知晓 **当前纪元的群组密钥**，而该密钥通过每日签名链获取：

* 每个纪元开始时（约 **每天一次**），Gonka 生成一个**新群组密钥**，并使用**上一个**纪元的密钥对其进行签名。
* 必须向以太坊桥接合约提交一笔小额交易以注册该新密钥。合约仅接受由前一个密钥签名的**下一个连续纪元密钥**——因此密钥历史形成一条从创世开始的完整链条。
* **任何人** 都可以使用相同的公开数据提交此更新。

一旦当前纪元的群组密钥被注册，提款将快速完成：**一个纪元签名可授权该纪元内发起的任意数量提款**。用户的流程如下：

1. 在 Gonka 上提交提款/铸造操作，指定**接收方以太坊地址**。此操作会燃烧/托管资产并触发使用群组密钥的 BLS 签名。
2. 获取生成的签名。
3. 将该签名连同转账数据提交至以太坊上的桥接合约，合约将使用当前群组密钥验证签名，并向接收方释放 ERC-20、ETH 或 WGNK。

### 如果当前纪元密钥尚未注册

提款使用当前纪元的群组密钥签名，而桥接合约必须已持有该密钥。在纪元切换后（约每天一次），合约可能短暂滞后，你的释放操作可能因 `InvalidEpoch` 失败，或仪表板显示桥接落后于链。你无需等待：任何人都可通过仪表板或手动推送缺失的密钥更新。参见 [桥接纪元更新](bridge-epoch-update.md)。

## 时间与最终性

转账时间取决于方向：

* **以太坊 → Gonka：约 15–20 分钟。** 桥接合约需等待存款区块在以太坊上**最终确认**（约两个纪元）后才铸造代币。Gonka 不使用任何前置资金并承担风险的中介，因此该等待不可避免。确切时间也取决于你的交易在以太坊纪元中的位置。
* **Gonka → 以太坊：快速。** 群组密钥每天生成一次并全天使用，因此你可在任何时间发起提款，仅需等待 BLS 签名和你的以太坊执行交易。

!!! warning "在 Gonka 链中断期间"
    桥接独立于 Gonka 块生产，摄取**最终确认的以太坊区块**。若 Gonka 链暂停，这些以太坊区块（及其包含的存款）可被主机**跳过**而非排队，直到签名恢复前无法签署提款。如果你在[仪表板](tracker-integration.md)上看到链被报告为宕机，请等待其恢复正常后再进行桥接。

## 桥接 vs 交易所

桥接仅**锁定一条链上的资产并在另一条链上释放**——它不进行资产互换。交易发生在**独立**的合约上。在 Gonka 上，封装代币可通过链上流动性池进行交换。

## 桥接 vs IBC

此桥接直接连接 Gonka 与**以太坊**。Gonka 也支持 **IBC** 以与其他 Cosmos 链转账（参见 [IBC](../ibc/withdraw-usdt-via-kava.md) 章节）。

* 使用**以太坊桥接**在**以太坊和 Gonka** 之间转移资产。通常比通过 IBC 路由更简单，且需要更少的 Gas 代币。
* 从以太坊桥接的代币在 Gonka 上以与此桥接绑定的封装 CW-20 形式存在。它可在 Gonka 内部转移并**返回以太坊**，但**无法**转发或出售至其他 Cosmos 链——如需此功能，应使用 IBC 原生资产。
