# 提款 GNK（以太坊 → Gonka）

这是 [存入 GNK（Gonka → 以太坊）](deposit-gnk.md) 的反向操作。它会在以太坊上燃烧封装的 GNK（**WGNK**），并从 Gonka 上的托管中释放等量的原生 **GNK**。

原生 GNK 将释放到与在以太坊上燃烧 WGNK 相同密钥所派生的 Gonka 地址。请确保你在 Gonka 上控制该密钥——参见 [地址和密钥](addresses-and-keys.md)。
