# 在 Discord 上获取支持

如果您需要帮助，请加入 [Discord](https://discord.gg/REcpeYc7P7) 上的 Gonka 社区。

要贡献代码或提出建议，请参阅 [悬赏计划](bounty-program.md)。请私下报告所有安全漏洞。不要在 GitHub 上公开创建问题或拉取请求，也不要将问题发布到 Discord 或其他公共渠道。要符合悬赏资格，请在 [HackerOne](report-vulnerability.md) 上提交。只有此提交才有资格获得奖励。如果您无法或不愿加入悬赏计划，请改在 [GitHub 上私下报告](https://github.com/gonka-ai/gonka/security/advisories/new)。通过这种方式提交的报告不符合悬赏资格。对于 HackerOne 报告，修复是可选的，且优先级较低：在 HackerOne 报告创建后，在 [`gonka-ai/gonka`](https://github.com/gonka-ai/gonka/) 上打开 **安全与质量 → 报告漏洞**，将 HackerOne 报告编号放入标题，然后从该报告创建私有分支，并在其中提交修复。
