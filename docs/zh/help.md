# 在 Discord 上获取支持

如果您需要帮助，请加入 [Discord](https://discord.gg/REcpeYc7P7) 上的 Gonka 社区。

要贡献代码或提出建议，请查看 [悬赏计划](bounty-program.md)。请首先在 [HackerOne](report-vulnerability.md) 上提交每个安全漏洞。只有该提交才可获得奖励。请勿在 GitHub 上公开创建问题或拉取请求，也勿在 Discord 或其他公开渠道发布该问题。修复是可选的，且居于次位：在 HackerOne 报告创建后，在 [`gonka-ai/gonka`](https://github.com/gonka-ai/gonka/) 上打开 **安全与质量 → 报告漏洞**，在标题中填写 HackerOne 报告编号，然后从该报告创建私有分支，并在其中提交修复。
